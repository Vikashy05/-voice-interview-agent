# Contributing to Full-Duplex Voice Interview Agent

Thank you for your interest in contributing to this project! We welcome contributions of all kinds, including bug fixes, new features, documentation enhancements, and feedback.

## How to Contribute

### 1. Reporting Bugs
- Search existing [Issues](https://github.com/Vikashy05/-voice-interview-agent/issues) to ensure the bug hasn't already been reported.
- If not, create a new issue using the **Bug Report** template.
- Include detailed steps to reproduce, expected behavior, and relevant logs.

### 2. Proposing Features
- Open an issue using the **Feature Request** template to discuss your ideas before submitting a Pull Request.

### 3. Submitting Pull Requests
1. Fork the repository.
2. Create a new branch for your feature or bug fix:
   ```bash
   git checkout -b feature/my-new-feature
   ```
3. Make your changes and test locally:
   ```bash
   ruff check .
   pytest
   ```
4. Commit your changes with a clear commit message:
   ```bash
   git commit -m "feat: add feature XYZ"
   ```
5. Push to your fork and submit a Pull Request against the `main` branch.

## Code Style
- Python code must adhere to PEP 8 standards.
- Run `ruff check .` to verify formatting and linting rules.
- Add unit tests for new functionality where applicable.

Thank you for helping improve the project!
